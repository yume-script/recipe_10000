# 만개의레시피 플러그인 (recipe_10000) v0.2.2

- **사이드바 메뉴**: 인기 랭킹, 카테고리 칩, 검색.
- **홈 위젯 "오늘의 인기 레시피"**: 홈 화면 플러그인 배치 모드를 켠 뒤 "+ 위젯 추가"에서 직접 고릅니다. 랭킹 10개를 날짜별로 돌려가며 6개 표시합니다.
- **레시피 읽기**: 레시피를 누르면 전체화면 리더가 열리고, 표지 사진·재료·만드는 순서가 한 페이지에 이어져 스크롤로 읽힙니다. 새 창 없이 같은 화면에서 열리며 Esc나 ✕로 닫습니다.

## 설치
1. `plugins/metadata/recipe_10000/` 로 복사 후 서버 재시작.
2. 환경설정 > 플러그인 설정에서 활성화.
3. 환경설정 > 외부 도메인에 `www.10000recipe.com` 등록.

## 구조
`script.js` / `dashboard.js` 는 공통 코드(파서 + 리더) 뒤에 각 화면 코드를 이어 붙인 파일입니다. 사이트 구조가 바뀌면 두 파일의 `parseList()` / `parseRecipe()` 를 같이 고치세요.
